# 성북구 정류장/역 데이터 (FR-5)

## seongbuk-subway-stations.json

성북구 관내 지하철역 12곳(4호선/6호선/우이신설선, namu.wiki 기준)의 이름과 대략적인 좌표를 담은 시드 데이터다.

**⚠️ 좌표는 검증되지 않은 근사값이다.** 웹 검색으로 확보한 참고 정보 기반으로 작성했으며, 공공데이터포털의 "서울교통공사 역사 좌표(위경도) 정보" 같은 공식 데이터로 교체 전까지는 소수점 정밀도가 필요한 용도(정밀 내비게이션 등)에 쓰지 않는다. MVP의 목적(팟 출발지 선택, 최단거리 정렬)에는 현재 정밀도로 충분하다고 판단해 우선 반영했다.

## 버스정류장 데이터는 아직 없음

FR-5는 버스정류장도 포함해야 하지만, 정확한 목록은 공공데이터포털(data.go.kr) 또는 서울 열린데이터광장의 오픈 API 인증키가 있어야 조회할 수 있다. 이 저장소에는 아직 키가 없어 버스정류장 시드는 비어 있다.

**필요 작업 (API 키 발급 후):**
1. data.go.kr 또는 data.seoul.go.kr에서 버스정류장 위치정보 API 인증키를 발급받는다.
2. `.env.local`에 `SEOUL_OPENAPI_KEY`(또는 `DATA_GO_KR_SERVICE_KEY`)를 설정한다.
3. `backend/scripts/seed-stations.ts`에 버스정류장 fetch 로직을 추가하고 성북구로 필터링한다.

키를 받으면 알려주시면 이어서 구현하겠습니다.
